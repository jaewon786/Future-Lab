> 통과 기준: 5점 또는 3분 경기 1판을 끝까지 치름, 충돌·연결 끊김 0회

## 방법
1. 노트북에서 `laptop/versus.html`(배포 `https://jaewon786.github.io/Future-Lab/laptop/versus.html`)을 연다.
2. "폰 + 웹캠"이면 화면의 QR을 폰으로 찍어 칼 컨트롤러를 열고 "센서 켜고 연결"을 누른다. "웹캠만"이면 바로 진행.
3. 처음에는 `?dummy=1`(허수아비 상대)로 찌르기가 득점되는지 확인하고, 그다음 난이도 보통으로 1판.
