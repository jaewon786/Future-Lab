> 상태: **시험 전** — 팀원이 실제 카메라로 진행하고 아래를 채운다.
> 통과 기준: 런지 10회 모두 감지 (F3), 판정 일치율 80% 이상 (PRD 지표)

## 방법
1. 노트북에서 `laptop/practice.html`(배포 주소 `https://jaewon786.github.io/Future-Lab/laptop/practice.html`)을 연다. 노트북은 피스트 옆, 측면에서 전신이 보이게 둔다.
2. 같은 동작을 기록기(`laptop/spikes/recorder.html`)로도 남긴다: 시작 직후 3초 이상 준비 자세 → 런지 10회(정상 5·오류 5), 각 런지 직후 `G`(좋은 런지) 또는 `B`(나쁜 런지).
3. 기록 파일을 `fixtures/practice/{이름}-{날짜}.json`에 넣고 `npm run eval:lunge` (왼손잡이면 `-- --left`).
