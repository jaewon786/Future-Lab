# 펜싱 코치 — 노트북·폰만으로 하는 찌르기 연습과 3D 가상 상대 대결

> 원본 계획서: https://claude.ai/artifact/PZEk5KSf7LCFbqbMqHhJVZ (2026-11-23 기준, rev 29)
> 이 PRD는 계획서의 1~5장, 8장, 10~11장을 요구사항 관점으로 옮긴 것이다. 구현 방법(스택, 알고리즘, 작업 분해)은 계획서 6·7·9장과 `/plan` 산출물에 둔다.

## Problem
혼자 펜싱을 연습하는 입문자·동호인은 자세를 봐 줄 코치도, 거리와 타이밍 감각을 줄 상대도 없다. 기존 대안은 실제 동작이 반영되지 않는 게임이거나 VR 헤드셋·체육관용 장비가 필요해, 이미 가진 노트북과 폰만으로는 자세 피드백과 대결 연습을 함께 할 방법이 없다.

## Evidence
- 경쟁 조사(계획서 2장): 조사 범위에서 폰 센서·자세 분석·3D 가상 상대를 한 앱에서 제공하는 서비스를 찾지 못함. FIE Swordplay는 동작 미반영, Ufence는 Meta Quest 필요, Fencer by Boxglass는 약 2,000유로 키트, SKT-FAN은 국가대표 내부용. 앱스토어 전수 조사는 아님.
- 사용자 문제 자체: Assumption — needs validation via 펜싱 동호인 3~5명 짧은 인터뷰 또는 수업 중 시험 사용 관찰.

## Users
- **Primary**: 혼자 연습하는 펜싱 입문·동호인. 집이나 연습실에서 노트북과 스마트폰을 갖고 있고, 레슨이 없는 날 런지 자세와 거리 감각을 연습하고 싶을 때 쓴다.
- **Secondary**: 수업 평가자 — 5분 시연을 보고 평가한다.
- **Not for**: 공식 경기 심판·판정 보조가 필요한 사람, 선수급 정밀 분석이 필요한 엘리트 선수, 여러 명이 동시에 대결하려는 사용자.

## Hypothesis
We believe **노트북 웹캠 자세 판정과 폰 센서 찌르기 감지를 합친 3D 가상 상대 대결** will **혼자서도 자세 피드백과 대결 연습을 함께 하게 해 줄 것** for **혼자 연습하는 펜싱 입문·동호인**.
We'll know we're right when **팀 외 사용자 5명이 설명 없이 보정부터 대결 1판까지 끝내고, 런지 판정이 팀원 라벨과 80% 이상 일치할 때**.

## Success Metrics
| Metric | Target | How measured |
|---|---|---|
| 런지 자세 판정 일치율 | 팀원 정상/오류 라벨 대비 80% 이상 | 라벨링한 런지 기록으로 평가 |
| 찌르기 감지 | 재현율 90% 이상, 오탐 10% 이하 | 찌르기 50회·일반 팔 동작 50회 기록 |
| 포즈 처리 속도 | 15fps 이상 (팀원 노트북 전부) | 프레임 카운터 |
| 종단 지연 | 동작→아바타 반영 150ms 이하 | 동작 시작부터 화면 반영까지 측정 |
| 폰→노트북 전송 지연 | p95 50ms 이하 | 연결 상태에서 왕복 시간 측정 |
| 웹캠·폰 동기화 오차 | 100ms 이하 | 박수 신호를 영상과 센서에서 각각 검출해 비교 |
| 시연 안정성 | 5분 시연 중 충돌·연결 끊김 0회 | 리허설 3회 |
| 사용성 | 팀 외 5명이 설명 없이 대결 1판 완료 | 시험 사용 관찰과 짧은 설문 |

모든 목표값은 측정 전 가정이며 기술 검증(마일스톤 1) 결과로 조정한다.

## Scope
**MVP** — 계획서 P0 기능: 웹캠 포즈 표시, 폰 센서 전송, 런지 감지와 자세 정상/오류 판정, 내 동작이 반영되는 3D 아바타와 상대 아바타, 거리에 따라 공격·방어·후퇴하는 규칙 기반 상대와 에페 타격 판정.

**Out of scope**
- 공식 판정·심판 보조, 플뢰레·사브르 우선권 판정 — 판정 복잡도가 커서 에페만 다룸
- 멀티플레이, 앱스토어 출시, 계정·서버 기능 — 수업 기간 안에 핵심 경험 검증에 불필요
- 부상 예방·실력 향상 효과 주장 — 검증 근거 없음
- 강화학습 상대, 리플레이, 음성 코칭 (P2) — MVP 이후
